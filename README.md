PR. 1 Fundamental Booster


Project Overview
PR. 1 Fundamental Booster is a comprehensive hands-on project designed to practice and master fundamental to advanced spreadsheet formulas, data manipulation techniques, dynamic lookup methods, and data analysis functions in Google Sheets / Excel.


Topics Covered
-Cell References & Formatting: Relative & Absolute References, Data Formatting, Data Input.
-Logical Functions: IF Formulas, Nested IFs, IF with AND/OR.
-Statistical Aggregation: COUNTIFS, SUMIFS, AVERAGEIFS.
-Lookup & Reference Functions: VLOOKUP, XLOOKUP, XMATCH.
-Dynamic Searching: INDEX / MATCH combinations.
-Text Manipulation: Text functions for string processing (LEFT, FIND, UPPER, LOWER).
-Dynamic References: INDIRECT and OFFSET.
-Date, Time & Math Functions: Date differences, Age calculation, ROUND, CEILING, FLOOR.
-Data Filtering: Dynamic array extraction using the FILTER function.


Essential Tasks & Key Objectives
1. Relative & Absolute Cell References, Formatting, and Data Input
-Enter and format data (bold, italic, currency, date, custom formats).
-Apply absolute ($A$1) and relative (A1) references correctly in formulas.

2. Logical Functions (IF & Nested IF)
-Classify students' grades based on their scores.
-Compute sales discounts based on custom price thresholds.

3. Logical Operators (IF with AND / OR)
-Identify students who scored above 80 in both Math & Science using IF(AND(...)).
-Determine whether a product is eligible for discount using IF(OR(...)).

4. Summary & Conditional Aggregations (COUNTIFS, SUMIFS, AVERAGEIFS)
-Count the number of students who scored above 50 in Math.
-Sum total sales for a specific region and product.
-Calculate the average score for students who scored above 60.

5. Lookup Functions (VLOOKUP, XLOOKUP, XMATCH, INDEX/MATCH)
-VLOOKUP: Find product prices from sales data.
-INDEX/MATCH: Find sales values for a specific salesperson in a specific month and perform dynamic lookups without column restrictions.
-XLOOKUP: Search salesperson performance based on flexible search criteria and fetch employee salaries dynamically without requiring sorted data.
-XMATCH: Find the exact position of a product in a sales list.

6. Text Manipulation Functions
-Extract the first name from full names using LEFT and FIND.
-Convert text strings to uppercase or lowercase using UPPER() and LOWER().

7. Dynamic Reference Functions (INDIRECT & OFFSET)
-Dynamically reference a cell range using INDIRECT.
-Create dynamic ranges for analyzing sales trends using OFFSET.

8. Date, Time & Math Functions
-Calculate age from date of birth.
-Calculate the difference in days between two dates.
-Perform financial rounding using ROUND(), CEILING(), and FLOOR().

9. Advanced Array Filtering (FILTER Function)
-Extract a list of top-performing students (grades > 80) dynamically based on scores.


Main Tasks & Deliverables
1.Grade Classification: Apply IF formulas to classify student grades.
2.Student Count: Use COUNTIFS to count students scoring above 60.
3.Price Lookup: Use VLOOKUP to find product prices from sales data.
4.Salary Lookup: Apply XLOOKUP to fetch employee salaries dynamically.
5.Employee Data Analysis: Format and analyze date of joining in Employee data.
6.Data Extraction: Use the FILTER function to extract students with grades above 80.


Deliverable Requirement
-Complete the given worksheets by applying the required formulas in respective sheets (Students Grade, Sales Data, Employee Data).
